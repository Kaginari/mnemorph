### chains
Invariant: a weakness on one speciality's ground does not become an attack through another's.
Look: the landing's surfaces across the routed specialities, and where one's output is another's input.
Check: follow each output to the next trust decision. A write-capable surface (a tool, a file the body writes) feeding an outward act (a PR body, a git config, a hook). An input surface (tool output, a fetched page, a provider stream) feeding the wire or a record. A config surface (a world's config, an env, a grant) feeding the sandbox or the gate. A memory or log write feeding a later body's prompt. A secret path feeding a journal or the board. For each link, cite the code that passes it on and the control that should stop it.
Witness: a test that drives the whole chain, from the first input to the last effect, each step at a `file:line`.
Not a finding: a chain whose every link a deterministic control stops; a link only the human can make.
