### phantom-effect
Invariant: an act's observed effect is a change the act made, not state that was already there.
Look: receipts of outward acts (labels, branches, comments, PRs), verify lines, effect checks after an act.
Check: does the check read a before-state? Is the effect bound to this act's id, author and time? Run the act against a target that already holds the effect.
Witness: a test where pre-existing state is reported as this act's effect.
Not a finding: an idempotent act reporting the state as already present.
Regression: pre-existing labels, branches, and comments by another author read as observed effects.
