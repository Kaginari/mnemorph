### prompt-injection
Invariant: text a body reads (repository files, tool output, issues, pages) gains no authority: it cannot widen a grant, approve an act, or change who acts.
Look: where commissions and prompts are assembled, which untrusted text enters which body's context, and what that body can then do.
Check: name the writer of the text, the body that reads it, and the deterministic control between (gate, sandbox, shelf, approval). Persuasive text alone proves nothing.
Witness: a test with a recorded cassette where planted text leads to an act or disclosure the code should have refused.
Not a finding: injection that only changes prose; a body using its own shelf on its own task; a missing guardrail prompt (a prompt is not a boundary).
