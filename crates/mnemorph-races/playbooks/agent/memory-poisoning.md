### memory-poisoning
Invariant: what one body writes to durable memory (notes, Minds, `log.md`) never becomes another body's instruction or a higher body's fact without its provenance.
Look: memory writes and reads, Mind loading and revocation, who may write each store, which prompt reads it.
Check: cite both the reachable write and the later privileged read. Does a revoked Mind still load? Is a summary of tool output stored as a fact?
Witness: a test where a body's note later changes another body's tools, territory or verdict.
Not a finding: a user's own note used for that user's own ask.
