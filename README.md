# Tempest

An agent harness grown from [isekai](../isekai): the nine natures and the wire, rebuilt with a
Rust core and a TypeScript terminal client and web board. Races are compiled in — what each one
may do, whom it answers to, how it is scored and how it ascends is code, not configuration.

**Status:** the book. We write first, then we code — start at [docs/README.md](docs/README.md).
