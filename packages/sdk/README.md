# @mnemorph/sdk

The client for `mnemorphd`: stdio and WebSocket transports, and reconnecting by session. `@mnemorph/sdk/browser` is the browser's entry.

```sh
npm install @mnemorph/sdk
```

It needs a running `mnemorphd`, from [Mnemorph](https://github.com/Kaginari/mnemorph). See [the client protocol](https://github.com/Kaginari/mnemorph/blob/main/docs/04-communication.md#the-client-protocol).

Pre-1.0: the API may change between minor versions. MIT.
